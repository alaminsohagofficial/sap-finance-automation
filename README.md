# SAP Finance Automation System

Automated financial settlement, LaTeX clearance document generation, and notification gateway dispatch system for SAP ERP operations.

## Features
- **ERP Settlement Tracking:** Standardized logging for SAP Doc Type DZ/SA transactions.
- **Automated PDF Generation:** High-quality LaTeX templates for financial clearance documents.
- **Notification Payloads:** Structured SMS & Email payload templates for automated dealer communications.
- **GitHub Actions Support:** Continuous Integration workflow for compiling LaTeX documents into PDFs.

## Structure
- `/documents` - LaTeX template files for official confirmations.
- `/payloads` - JSON schemas for SMS and Email gateways.
- `/.github/workflows` - CI/CD actions for automated compilation.
